# Knob Adjustment

How to remove and replace or reorient the EQ knobs on the Atom Phono.

**Difficulty:** Easy  
**Time:** 5 minutes  
**Tools:** 1/16" allen wrench

---

<div class="repair-step">
  <div class="repair-step-media">
    <img src="/img/atom-phono/allen-wrench.png" alt="Allen wrench seated in the knob set screw" />
  </div>
  <div class="repair-step-content">
    <div class="repair-step-header">
      <span class="repair-step-number">1</span>
      <h3 class="repair-step-title">Remove the Knob(s)</h3>
    </div>
    <ul>
      <li>Use a 1/16" allen wrench to loosen the set screw on the side of the knob</li>
      <li>Once the set screw is loose, pull the knob straight off the shaft</li>
    </ul>
  </div>
</div>

<div class="repair-step">
  <div class="repair-step-media">
    <img src="/img/atom-phono/knob-removed-wrench.png" alt="Knob removed from the shaft with the allen wrench in the set screw" />
  </div>
  <div class="repair-step-content">
    <div class="repair-step-header">
      <span class="repair-step-number">2</span>
      <h3 class="repair-step-title">Reposition and Secure</h3>
    </div>
    <ul>
      <li>Reposition the knob as needed</li>
      <li>Tighten the set screw with the 1/16" allen wrench to secure the knob in place</li>
    </ul>
  </div>
</div>
